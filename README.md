# ⚡ ELECTRA - Modern E-Commerce Tech Store

ELECTRA adalah platform e-commerce modern yang dibangun dengan fokus pada kecepatan, desain bersih, dan integrasi database real-time. Proyek ini menghubungkan antarmuka pengguna yang responsif dengan ekosistem database cloud untuk manajemen produk yang dinamis.

## 🚀 Fitur Utama
- **Dynamic Product Fetching**: Data produk ditarik secara otomatis dari database.
- **Dynamic Routing**: Halaman detail produk dibuat secara otomatis berdasarkan informasi dari database.
- **Data Mapping**: Sinkronisasi antara skema database dengan komponen UI secara efisien.
- **Responsive UI**: Pengalaman belanja yang optimal di perangkat mobile maupun desktop.

## 🛠️ Tech Stack
- **Framework**: Next.js (App Router)
- **Database**: Supabase
- **Styling**: Tailwind CSS
- **Language**: TypeScript
